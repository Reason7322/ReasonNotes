# Lucide SVG icon assets

Original upstream vector sources: https://github.com/lucide-icons/lucide

- `save.svg`: Lucide Save
- `refresh-cw.svg`: Lucide RefreshCw (used for Sync)
- `trash.svg`: Lucide Trash (the trash-can visual used for Delete)

The upstream LICENSE file is included alongside the SVGs. This source set
was retrieved from the Lucide main branch for the ReasonNotes desktop UI.

Qt renders these assets at the current display's physical-pixel density.
Their colors are applied at runtime from ReasonNotes' QML theme.
